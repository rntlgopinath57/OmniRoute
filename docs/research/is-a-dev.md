# is-a.dev for AI Team testing

Source: https://github.com/is-a-dev/register (MIT licence); instructions: https://docs.is-a.dev/.

The service offers free developer subdomains by reviewing DNS registration pull requests. It supplies a hostname, not web hosting, test automation, authentication, or a cure for cold starts. It may be useful as a memorable address for a public-facing AI Team demo or test endpoint once that endpoint has its own access controls.

Before use: choose an available name and a deployed target; check whether the endpoint should be publicly reachable; protect keys, internal dashboards, and test data; follow the upstream manual registration instructions (its README explicitly asks applicants not to generate registration requests with AI); then verify DNS, HTTPS, redirects, and rollback. No registration or deployment is part of this note.
